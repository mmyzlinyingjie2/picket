# 照相间 · 证件照转换工具

一个无需安装依赖的本地证件照转换网页。照片在浏览器中处理，不会上传到应用服务器。

## 运行

需要 Node.js 18 或更高版本：

```bash
npm start
```

浏览器打开 <http://localhost:3000>。

## 功能

- 上传或拖放 JPG、PNG、WebP 图片（最大 20 MB）
- 拖动、缩放并预览裁切
- 选择身份证、港澳通行证、社保卡、一寸照、二寸照规格，或输入自定义尺寸
- 导出 JPG、PNG、WebP
- 本地调整透明区域的底色

证件照规格会因地区和办理渠道而不同，请以受理机构的最新要求为准。毫米尺寸按设定 DPI 换算为输出像素；浏览器导出不写入 DPI 元数据。
